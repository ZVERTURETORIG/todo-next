# Todo Next

Простой список дел на Next.js. Можно добавлять задачи, отмечать их выполненными, редактировать двойным щелчком, удалять с подтверждением и искать по тексту. Список сохраняется в браузере после обновления страницы.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Для проверки типов используйте `npx tsc --noEmit`, для production-сборки — `npm run build`.

## Возможности

- Добавление задач и отметка выполнения.
- Фильтры «Все», «Активные» и «Выполненные».
- Удаление с подтверждением «Удалить задачу?».
- Редактирование двойным щелчком: Enter сохраняет, Escape отменяет.
- Поиск без учёта регистра, который работает вместе с фильтром.
- Кнопка × очищает поиск; если совпадений нет, показывается сообщение с запросом.
- Данные списка сохраняются в `localStorage` под ключом `todo-next-tasks`.
- Ctrl+K (или Cmd+K на Mac) переводит фокус в поиск.

## Карта проекта

| Путь | Что находится в файле |
| --- | --- |
| `app/page.tsx` | Главный компонент: состояние задач `tasks`, текст поиска `searchQuery`, фильтр `filter`, обработчики добавления, отметки, удаления и редактирования. В `visibleTasks` задачи отбираются по фильтру и поисковому запросу. Здесь же задачи загружаются из `localStorage` и сохраняются после изменений. |
| `app/layout.tsx` | Общий HTML-каркас страницы, язык и метаданные приложения. |
| `app/globals.css` | Цвета, отступы, кнопки, список задач и адаптация интерфейса для узких экранов. |
| `package.json` | Команды запуска и зависимости Next.js, React и TypeScript. |
| `tsconfig.json` | Настройки строгой проверки TypeScript. |

## Технологии

Next.js App Router, React, TypeScript и обычный CSS.
